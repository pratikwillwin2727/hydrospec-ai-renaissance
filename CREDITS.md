# HydroSpec AI — Credits & Tech Stack Acknowledgments

Welcome to the official repository credits for **HydroSpec AI**, developed for the **CSI KJSSE Renaissance Buildathon** at Somaiya Vidyavihar University.

## 🛠️ Technology Stack & Libraries

### Frontend & UI Architecture
* **React (v18+)** — Component-based user interface architecture.
* **Vite** — Next-generation frontend tooling and lightning-fast local development server.
* **Tailwind CSS** — Utility-first CSS framework powering the dark-lab forensic HUD and responsive layout.
* **HTML5 Canvas API** — Core rendering engine for real-time micro-fluidic droplet surface physics (Tab 1) and Sobel edge detection filters (Tab 2).
* **Lucide React** — Modern iconography suite for clean UI indicators.

### Buildathon & Collaboration Tools
* **GitHub & Git** — Version control, sequential progress tracking, and remote repository hosting (`hydrospec-ai-renaissance`).
* **Google Chrome & Developer Tools** — Local network testing and debugging across mobile and desktop viewports.
* **Canva & ReportLab** — Presentation deck design and documentation generation.
